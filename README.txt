## GitHub Pages
1. Репозиторий түзүңүз.
2. ZIP ичиндеги файлдарды репозиторийдин негизги папкасына жүктөңүз.
3. Settings → Pages → Deploy from a branch → `main` → `/root`.
4. Save басыңыз.
5. GitHub берген `github.io` шилтемени ачыңыз.
